# 스토리 모드 「사르말의 원혼」 — 설계

- 날짜: 2026-10-02
- 상태: 승인됨 (섹션별 합의 완료)
- 범위: 에피소드 3개, 전쟁터에 나타난 귀신 컨셉

## 1. 목표와 범위

기존 자유 전투(시장 거리 FPS)를 그대로 두고, 그 위에 서사가 있는 스토리 모드를 얹는다.

**포함**
- 부팅 전 타이틀 화면(스토리 모드 / 자유 전투)과 에피소드 선택
- 에피소드 3개: 컷신(코덱스 생성 일러스트 + 자막) + 인게임 무전 자막 + 목표
- 귀신 적: 병사 원혼, 민간인 원혼(환영), 보스 「검은 장교」
- 사망 시 재시작, 클리어 진행 저장

**제외**
- 인간 적과 귀신 사이의 AI 대 AI 교전 (현재 AI는 플레이어만 노리는 구조) — 무전·연출로만 표현
- 새 맵 — 기존 시장 거리 하나를 시간대·안개·적 배치·목표 지점으로 변주
- 음성 더빙 — 모든 대사는 한국어 자막
- AI 메쉬 귀신 — 지금은 코드(three.js 절차적 생성)로 만들고, 나중에 교체 (6장 참고)

## 2. 스토리

### 배경
가상 도시 '사르말'의 시장 거리. 3년 전 연합군 작전 중 이 광장에서 피란민 41명이 사살됐고, 군은
"교전 중 사망"으로 기록을 덮었다. 플레이어는 신속대응팀 '레이븐 분대'의 **레이븐 2**. 이 거리에서
실종된 정찰분대 '섀도'를 찾으러 들어간다.

### EP1 「잡음」 — 해질녘(18:40), 옅은 안개
- **인트로:** 수송 차량 안 브리핑. 섀도 분대의 마지막 신호는 시장 거리.
- **플레이:** 거리 진입 → 인간 무장세력과 교전(기존 AI) → 섀도 분대 마지막 위치(폐허 마당) 도달.
- **이상 현상(맛보기):** 무전 잡음 속 아이 목소리 자막("…엄마 어디 있어요?"), 골목 끝에 민간인 원혼이
  1~2회 보였다 사라짐, 거리 조명 깜빡임.
- **아웃트로:** 섀도 분대원들의 시신. 헬멧 카메라 마지막 영상에 죽은 자들이 걸어오는 모습.
  그 순간 등 뒤에서 쓰러졌던 적들이 일어선다.

### EP2 「일어선 자들」 — 밤(22:00), 짙은 안개
- **인트로:** 본부 무전 두절. 무장세력도 무언가에게 쫓기고 있다.
- **플레이:** 인간 적 + 병사 원혼 혼합. 무전 중계기 3곳 재가동(지점 도달 → F키 → 30초 버티기).
- **아웃트로:** 중계기로 3년 전 무전 녹음 수신 — "광장의 민간인 전원 제압. 기록은 남기지 마라."
  명령한 목소리는 우리 측 지휘관 **크레인 소령**.

### EP3 「원혼」 — 자정(00:30) → 새벽(05:40)
- **인트로:** 학살 현장인 광장으로.
- **플레이:** 귀신만 등장. 원혼 3웨이브 생존 → 보스 「검은 장교」(크레인 소령의 망령, 학살 뒤
  이곳에서 죽음, 원혼들을 붙잡아 두고 있음).
- **엔딩:** 보스 처치 → 하늘이 실제로 새벽으로 흐르고 원혼들이 흩어짐. 레이븐 2는 헬멧 카메라 영상과
  녹음을 들고 귀환. 진실이 밝혀질 것을 암시.

### 공통 규칙
- 에피소드당 약 5~8분.
- 사망 → "전사" 화면 → 같은 에피소드 재시작(인트로 컷신 건너뜀).
- 클리어 시 다음 에피소드 해금(localStorage).
- 모든 텍스트 한국어.

## 3. 실행 흐름

```
페이지 열림 ─▶ 타이틀 ─┬─ [자유 전투] ─▶ 지금과 동일하게 부팅·플레이 (story 시스템 미등록)
                      └─ [스토리 모드] ─▶ 에피소드 선택
                                            │
   인트로 컷신 재생  ‖  동시에 뒤에서 엔진 부팅 (로딩 시간을 컷신이 가림)
                                            ▼
   플레이 (에피소드 스크립트가 목표·무전·적 등장·공포 연출을 순서대로 실행)
     ├─ 클리어 ─▶ 아웃트로 컷신 ─▶ 진행 저장 ─▶ ?mode=story&ep=<다음> 으로 새로고침
     └─ 사망 ──▶ "전사" 화면 ─▶ ?mode=story&ep=<같은>&skipIntro=1 로 새로고침
```

- 에피소드 전환과 재시작은 **페이지 새로고침**으로 한다. 서브시스템 리셋 API를 새로 만들지 않아도 되고,
  이전 에피소드의 래그돌·데칼·AI 상태가 새어 나올 일이 없다.
- 엔진 부팅(4~10초)은 인트로 컷신과 병렬로 진행한다. 컷신이 먼저 끝나면 "작전 준비 중" 표시 후 대기.
- `?capture=1`이면 타이틀을 건너뛴다 → 기존 캡처·검증 도구 영향 없음.
- 스토리 모드에서는 ESC 일시정지 메뉴에 "타이틀로" 버튼을 추가한다.

### 에피소드 스크립트 형식

에피소드는 코드가 아니라 데이터다. 4화, 5화는 데이터 파일만 추가하면 된다.

```js
export default {
  id: 1,
  title: '잡음',
  hour: 18.67,
  weather: { fogDensity: 0.02 },
  spawn: { at: [0, 40], yaw: Math.PI },
  intro: [{ img: 'ep1_intro_1', lines: ['…'] }, /* … */],
  outro: [/* … */],
  steps: [
    { do: 'objective', id: 'enter', text: '시장 거리 진입' },
    { do: 'reach', at: [0, 30], radius: 6 },
    { do: 'radio', who: '본부', text: '레이븐 2, 섀도의 마지막 신호는 동쪽 골목 뒤다.' },
    { do: 'spawn', units: [{ type: 'irregular', at: [-4, 12] }] },
    { do: 'killAll' },
    { do: 'haunt', kind: 'apparition', at: [18, 4] },
    { do: 'hold', at: [20, -22], seconds: 30 },
    { do: 'outro' },
  ],
};
```

단계 종류(초안): `objective`, `clearObjective`, `radio`, `wait`, `reach`, `spawn`, `killAll`, `killCount`,
`hold`, `interact`, `haunt`, `sky`, `boss`, `outro`. 좌표는 레벨 좌표(`world.levelToWorld`로 변환).

## 5. 귀신

### 5.1 행동과 외형의 분리

```
src/ai/ghost/
  behaviour.js      행동: 순간이동, 흩어짐/재형성, 냉기 피해, 소멸, 보스 페이즈
  bodies/
    index.js        외형 등록: kind → 생성 함수
    soldier.js      병사 원혼: 기존 병사 메쉬 + 귀신 셰이더
    officer.js      검은 장교: 검은 연기 재질 + 붉은 눈, 1.25배
    wraith.js       민간인 원혼: 코드로 만든 천 두른 반투명 형체, 천자락 흔들림
```

- 외형 계약: `{ object3D, update(dt), setFlicker(v), setDissolve(t), dispose() }`. 행동은 외형 내부를 모른다.
- **판정 몸체는 분리**: 피격 캡슐(머리·몸통·팔다리)과 애니메이션은 보이지 않는 기존 `RIG` 뼈대가 담당한다.
  외형은 그 뼈대를 따라가는 껍데기다. 외형을 바꿔도 헤드샷·이동은 그대로다.

### 5.2 외형 (현재: 코드)
- 창백한 청백색, 프레넬 림 글로우, 세로 노이즈 깜빡임, 간헐적 버텍스 글리치, 반투명.
- 발밑·몸 주변 안개 입자(`fx.haze` 재사용).
- **렌더 리스크:** 렌더러는 `transparent` 재질을 프리패스(깊이·노멀·속도)에서 빼고 그린다. TAA 잔상이
  생길 수 있다. 구현 첫 단계에서 귀신 하나를 띄워 실제 화면으로 판단하고, 나쁘면 디더 반투명
  (`alphaHash` 계열)으로 전환한다.
- **프리웜 계약:** 귀신 재질은 `ai.prewarmMaterials()`에서 미리 컴파일한다. 첫 등장 프레임의 셰이더 컴파일
  정지(수백 ms)를 막기 위함.

### 5.3 행동

| | 인간 적 (기존) | 병사 원혼 |
|---|---|---|
| 이동 | 엄폐물 찾아 피킹 | 엄폐 없이 천천히 접근 |
| 특수 | 수류탄, 측면 우회 | 순간이동: 시야에서 벗어나면 사라졌다가 더 가까운 곳에 재출현 |
| 피격 | 부위별 반응, 다리 맞으면 감속 | 짧은 시간 큰 피해 시 안개로 흩어졌다가 3~5m 옆에서 재형성 (1.5초 무적) |
| 공격 | 정확한 소총 사격 | 짧고 부정확한 사격 + 2.5m 이내 냉기 피해와 화면 왜곡 |
| 사망 | 래그돌 | 래그돌 없이 2초 디졸브 + 안개 폭발 |
| 체력 | 100 | 160 (헤드샷 배율 유지) |

**보스 「검은 장교」:** 1.25배, 검은 연기 재질 + 붉은 눈, 체력 2,000 / 3페이즈. 페이즈 전환마다
비명 + 순간이동 + 병사 원혼 3명 소환. 화면 상단 보스 체력 바.

**민간인 원혼:** 전투하지 않는 연출용. 골목 끝·창문에 잠깐 서 있다 사라진다.

## 6. 향후 교체: AI 메쉬 귀신

`bodies/gltf.js`를 추가해 `.glb`를 불러오는 외형을 만들고 `bodies/index.js` 등록을 바꾼다.
`GLTFLoader`는 `three/addons`에 포함되어 있어 새 의존성이 없다. 리깅된 메쉬면 `RIG` 뼈대에 리타깃,
리깅이 없으면 몸통 본에 부착한다. 연결 방식은 메쉬를 받을 때 정한다.

## 8. 저장소 규칙 준수

`ARCHITECTURE.md`의 규칙을 스토리 코드에도 적용한다.
- `Math.random()` 금지 → `ctx.rng.fork()`
- 프레임당 할당 금지 → 벡터·배열은 `init()`에서 미리 할당
- 만든 리소스는 `dispose()`에서 해제
- 새 npm 의존성 없음
- 예외: 원작의 "이미지 파일 없음" 원칙은 **스토리 모드 컷신에 한해** 깬다. 자유 전투는 여전히 이미지 없이 돈다.

## 9. 검증

- **회귀:** `tools/baseline.mjs` + `tools/imagediff.mjs`로 변경 전후 11개 샷 비교 → 자유 전투 픽셀 동일.
- **빌드:** `npm run build` 통과.
- **로직:** 단계 실행기·트리거 판정은 `src/story/selftest.mjs`(Node, 가짜 ctx)로 검증.
